## ✅ The Easiest Installation Ever

**Your ONLY job:**
```bash
python install_mark_xlviii.py
```

- ✅ Clones the Mark XLVIII repository
- ✅ Installs ALL dependencies (rarfile, py7zr, wikipedia-api, PyQt6, PyOpenGL, etc.)
